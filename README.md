# Listening Garden booklets

Album notes, listening studies, interactive spatial drawings, and companion recordings.

- [Browse the collection](https://listening.garden/)
- [Wild Grafting](https://listening.garden/wild-grafting/)
- [Wild Grafting on Bandcamp](https://listeninggarden.bandcamp.com/album/wild-grafting)

Each album has its own directory and permanent page address. The site is plain HTML, CSS, and JavaScript with finished audio files. GitHub Pages publishes the `main` branch. Offline companion folders are available under Releases.

Listening-study convention: accompany each recording with a compact ambisonic view based on its retained score and spatial controls. Use the matching edition's note activity; a shared spatial path does not imply identical notes. Keep the time slider directly below the sphere on phones. Load recordings only when requested and field data as views enter the page; preserve reduced-motion and offline support.

The published Wild Grafting companion includes six short paired comparisons and the complete Garden Voices bonus album. Keep the full Wild Grafting recordings out of this public repository and offline downloads; link listeners to Bandcamp for the released album.

Editable sketches are separate from recorded arrangement maps. Label drawing-only controls clearly, and keep the listening companion focused on the sound material and musical relationships.
