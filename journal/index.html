A NOTE FROM ERIC

Over six months in Listening Garden, I built tools while playing with their sounds. Looking back now, I remember early experiments like AI Boyfriend and Eric 2.0, and getting the Claude API working. Plans passed between GPT and Claude as they checked each other; listening tests became my side of that exchange because the systems could not hear as I do.

I keep returning to software as a signal: code accumulating like sediment, becoming an information processor much like an audio processor. What happens when software development approaches the speed of an oscillator? These systems can turn musical knowledge into working tools quickly, but I still decide what to hear, keep, and change.

These first notes move from a history of shared decisions in composition to a proposed longer experiment, then into the sounds of Feral Current.
